## Implemented control slice and limits

- Migration `202611110007_command_audit_controls` adds optional scoped audit operation/target/reason fields with legacy workspace compatibility, unique financial audit per operation, immutable evidence and deferred action/target validation. It hardens CORRECT against reversing its own same-operation replacement. Readiness is 7. Applied 001–006 files are unchanged.
- `src/lib/ledger/{invariant-manifest,invariants}.ts` captures CHECK/trigger/function/security/ACL/ownership/column/index/enum/migration metadata and compares exact reviewed state. App import boundary is server-only; CLI imports the internal mechanics without environment I/O. REPEATABLE READ read-only capture pins the schema search path. SQL literals/source remain untouched by role alias normalization.
- `npm run ledger:attest` compares the actual local test schema to a new seven-migration reference. It is a local operator check, not a hosted verification or a runtime write flag; it rejects hosted/public-profile misuse. CI/local pipeline require it. Private-schema rehearsal separately tests restricted-role audit and captures reviewed read-only privilege state.
- Strict payload hashing, authenticated HTTP commands, complete transaction retry orchestration and mandatory per-command financial audit insertion remain S06B/C. Schema support deliberately does not retroactively invent audits for legacy receipts/raw SQL fixtures. The CLI alone does not authorize writes or complete the S06 gate.
